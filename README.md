# 宮崎市観光統計 インタラクティブWEBレポート（平成25年〜令和7年 13年間の軌跡）

宮崎市が発行した13年分（平成25年〜令和7年）の公式「宮崎市観光統計」PDF資料を構造化し、**Monadスタイル（editorial tech journal on warm parchment）**で再設計されたインタラクティブWEBレポートです。

ページを開いた瞬間から、平成25年(2013年)から令和7年(2025年)までの13年間の変遷が**デフォルトで1倍速（1.0x）にて流れるように自動再生**され、ウォームパーチメント基盤上で美しいセリフ見出しと等幅フォント、各種チャートが明晰に推移します。

---

## 🌟 主な機能と特徴

### 1. タイムラインスライダー & 1倍速デフォルト自動再生
- **1倍速デフォルト起動**: ページ読み込み完了と同時に、1.0x（1.5秒間隔）でタイムラプス再生を自動開始。
- **連続ループ再生**: 令和7年に到達すると自動的に平成25年に戻り、途切れることなく連続ループ。
- **ユーザー制御**: 中央の「❚❚ / ▶」ボタンでの一時停止・再開、スライダードラッグ、0.5x・1.0x・2.0xの再生速度切り替えに対応。

### 2. 動的カウンター & MonadフィーチャーKPIカード
- 年次切り替え時に数値がスムーズにカウントアップ/ダウンするローリングアニメーション。
- **Total Visitors**: Periwinkle Mist（`#cfdaf5`）のアクセントカード。
- **Overnight Stays / Inbound Guests / Tourism Spending**: 40px角丸パーチメントカード。
- 県外客 vs 県内客、宮崎地区 vs 青島地区の動的プログレスバーと前年比（YoY）ステータスバッジ。

### 3. 多角的なビジュアライゼーション（5大チャート）
1. **13年間マクロ推移グラフ**: 入込客数（Lake Blue実線）と宿泊客数（Off-Black破線）の長期推移。選択中年度のノードがハイライト。
2. **外国人宿泊客 国・地域別構成比**: 韓国・台湾・香港・中国・欧米・その他市場のシェア比率（Monadパレット）。
3. **月別季節リズムグラフ**: 2月の春季キャンプ、5月GW、8月夏休み、秋のイベントピークを可視化。
4. **主要観光施設来場者数**: 青島神社、宮崎神宮、道の駅フェニックス、フェニックス自然動物園、フローランテ宮崎などの来場動向。
5. **観光消費額 費目別内訳**: 宿泊費、みやげ品費、交通費、飲食・雑費の支出構造。

### 4. 2年比較シミュレーター（年度を指定して比較）
- **初期表示＆リアルタイム比較**: ページ読み込み完了時から即座に最新年度（令和7年）と前年度（令和6年）がセットされ、全6大指標（入込客数・延べ宿泊・インバウンド・消費額・宿泊単価・春季キャンプ来場）の差分（実数・増減率）と直接対比バーチャートが完全表示されます。
- **自由な2年度比較**: ドロップダウンから任意の2年度を選択するとリアルタイムに差分とグラフを自動再計算。
- **固定ナビゲーション**: 上部ナビゲーションバーの「年度を指定して比較」ボタンをクリックすればいつでも瞬時に比較セクションへスムーズスクロールします。

### 5. 13年間の4大構造変化と総括インサイト
1. コロナ危機からのV字回復と宿泊・滞在型観光への確かな転換
2. 外国人宿泊客（インバウンド）が過去最高18.5万人へ飛躍（台湾市場の急伸・直行便再開）
3. メガイベント（WBC侍ジャパン宮崎合宿、ひなたフェス2024、市制100年祭）の経済牽引力
4. 観光消費額が1,500億円規模へ倍増・宿泊単価の高付加価値化（約8,000円 → 約20,000円へ）

### 6. 宮崎市観光のあゆみ（歴史年表テープ）
- 昭和34年（巨人軍キャンプ開始）から令和7年までのマイルストーンを一覧表示。各出来事をクリックすると該当年度のダッシュボードへジャンプ。

### 7. 全13年データリポジトリ & ワンクリックCSV出力
- 全13年分の数値を一覧表で確認でき、インクリメンタル検索に対応。UTF-8 BOM付きCSVファイルを即時ダウンロード可能。
