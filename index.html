      STRUCTURAL ANALYSIS // 13年間の軌跡

      13年間の構造変化と総括インサイト // Macro Insights

      平成25年〜令和7年の13年間で宮崎市観光が遂げた4つの決定的な構造転換をデータから紐解きます。

      // STRUCTURAL INSIGHT 01

      1. コロナ危機からのV字回復と「宿泊・滞在型」への確かな転換

      平成25年〜令和元年にかけて年間約600万人水準で推移していた観光入込客数は、令和2〜3年のコロナ禍で約320〜370万人台へと急減しました。しかし令和4年以降、行動制限緩和と全国旅行支援により急速に回復し、令和5年には618万人、令和6年611万人、令和7年586万人とコロナ前水準を完全に回復。
      特に注目すべきは、延べ宿泊客数が令和元年（259.8万人）に迫る253.6万人まで増加しており、日帰り通過型観光から滞在・宿泊型へのシフトが結実しています。

      // STRUCTURAL INSIGHT 02

      2. 外国人宿泊客（インバウンド）が過去最高18.5万人へ飛躍

      インバウンド宿泊客数は、コロナ禍の令和3年に5,097人（約97%消失）にまで壊滅的な打撃を受けました。しかし水際制限の撤廃後、タイガーエア台湾の就航、チャイナエアライン台北線の増便、アシアナ航空ソウル便の増便、そして歴史的円安が強力な追い風となり、令和7年には史上最多の184,922人（前年比+35.0%）を記録。台湾市場は33,687人（前年比+81%増）と急拡大し、韓国（58,772人）に次ぐ柱として定着しました。

      // STRUCTURAL INSIGHT 03

      3. メガイベントとプロ野球春季キャンプの圧倒的経済牽引力

      宮崎市の観光サイクルは、2月の「プロ野球春季キャンプ」と国家的メガイベントによって大きなピークを刻みます。

      • 平成25・29年・令和5年：WBC（侍ジャパン）宮崎合宿。特に2023年（令和5年）はダルビッシュ有選手ら集結により、2月単月で史上初の100万人突破（100.7万人）を達成。
      • 令和6年9月：日向坂46「ひなたフェス2024」がひなたサンマリンスタジアム宮崎で開催。通常は夏休み明けで落ち着く9月の入込客数が41.0万人に跳ね上がり、全国のファンが市内を巡礼。
      • 令和6年11月：宮崎市制100周年記念イベント「SMILE MIYAZAKI 100年祭」が開催され、市民一体の祝祭ムードを創出。

      // STRUCTURAL INSIGHT 04

      4. 観光消費額が1,500億円規模へ倍増・宿泊単価の高付加価値化

      観光消費額総額は、平成25年の718億円から、コロナ底（令和3年: 406億円）を経て、令和5年には1,536億円（過去最高）、令和7年も1,478億円と高位推移しています。
      特筆すべきは、1人当たり宿泊消費単価の上昇（平成25年: 8,018円 → 令和6・7年: 約19,800円〜19,900円へと2.5倍に伸長）であり、インバウンド比率の増加と宿泊高付加価値化が観光消費総額を倍増させています。
